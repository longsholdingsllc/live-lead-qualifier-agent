Live Lead Qualifier

Instant, rule-based lead scoring. Send a lead, get a 0–100 score and a qualify / nurture / disqualify recommendation in milliseconds — deterministic keyword rules, the same result for the same lead, every time. No machine learning, no black box.

The endpoint

POST/api/qualify

Accepts a JSON lead with any of: name, email, company, title, message, budget, timeline. All fields are optional — the more signal, the higher the possible score.

Request:

curl -X POST https://live-lead-qualifier-agent.vercel.app/api/qualify \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Alex Rivera",
    "email": "alex@growthco.io",
    "company": "GrowthCo",
    "title": "Head of Revenue Operations",
    "message": "We process 200+ inbound leads per week manually. Looking for a system that can score them automatically before they hit our CRM.",
    "budget": "5k-15k",
    "timeline": "this quarter"
  }'

Response:

{
  "success": true,
  "score": 100,
  "max_score": 100,
  "recommended_action": "qualify",
  "reason": "Title indicates decision-maker in relevant function (+30); ...",
  "summary": "Lead scored 100/100 → QUALIFY",
  "lead_received": { "name": "Alex Rivera", "email": "alex@growthco.io",
                     "company": "GrowthCo", "title": "Head of Revenue Operations" },
  "timestamp": "2026-10-27T14:00:00.000Z",
  "agent": "Live Lead Qualification Agent v1.0"
}

Leads that score qualify are automatically forwarded to Long's Holdings by email — nothing hot gets thrown away.
